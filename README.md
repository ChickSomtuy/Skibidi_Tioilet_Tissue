# Skibidi_Toilet_Tissue

โครงงาน Skibidi Toilet Tissue เป็นนวัตกรรมที่พัฒนาเพื่อยกระดับความสะดวกสบายในการใช้งานกระดาษทิชชู่ในห้องน้ำ ด้วยระบบ จ่ายกระดาษทิชชู่อัตโนมัติ ที่ควบคุมผ่านเซนเซอร์อัจฉริยะและมอเตอร์แบบกำหนดการทำงานที่แม่นยำ

ฟังก์ชันหลักของอุปกรณ์:
ระบบตรวจจับด้วย Infrared Proximity Distance Senso: เมื่อตรวจพบว่ามีมือของผู้ใช้งานอยู่ใต้เซนเซอร์ ระบบจะสั่งการให้ มอเตอร์ตัวที่ 1 ทำการปล่อยกระดาษทิชชู่ลงมาสู่ตำแหน่งที่เตรียมไว้

การพับกระดาษอัตโนมัติ: ทันทีที่กระดาษทิชชู่ถูกปล่อยออกมา มอเตอร์ตัวที่ 2 จะทำหน้าที่พับกระดาษให้เป็นระเบียบ เพื่อให้ผู้ใช้งานสามารถดึงใช้งานได้อย่างง่ายดาย

ระบบแจ้งเตือนปริมาณกระดาษ: อุปกรณ์สามารถตรวจสอบปริมาณกระดาษทิชชู่ที่เหลืออยู่ภายใน หากพบว่าทิชชู่หมด ระบบจะส่ง การแจ้งเตือนไปยังสมาร์ทโฟนของแม่บ้านหรือผู้ดูแล โดยอัตโนมัติ เพื่อให้เติมกระดาษได้ทันท่วงที
